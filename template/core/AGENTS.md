## Hard invariants

1. **One role, one home.** A fact a reader may rely on has exactly one authoritative location. Every other mention is a link.
2. **English only.** Prose, comments, test names, commit messages.
3. **No empty directories, no speculative roles.** A directory appears when its trigger does, with its README in the same commit.
4. **Budgets carry a unit and a command.** Volume is non-whitespace characters; entries are rows. See `docs/conventions.md`.
5. **Generated files declare their command** on the first line: `generated by <command> — do not edit`.
6. **No secrets, no destructive commands.** A credential stays in the environment, never in a tracked file; a destructive command needs explicit instruction.
