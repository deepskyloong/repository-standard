# B-0001 — First deferred item

## Problem

What is not being decided now, and why it matters.

## Evidence

The facts that make this worth revisiting: a count, a command output, an incident. A claim without evidence is a wish.

## Revisit when

The event that makes this actionable — a condition outside it, or a freed slot in the plan. Not a date. When it fires, decide one of: start, defer again, or close. Do not delete the file or its index row.
