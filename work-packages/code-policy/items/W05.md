# W05 — Return coded findings from this repository's checker

**Depends on**: W03

The live instance. `Finding` is `{ level, message }`, and every check builds the sentence at the point it fires — `fail(\`missing required file: ${name}\`)`. Nothing carries a code or the facts, so a consumer cannot group, suppress, or test a message without parsing English. The refactor gives the record a code and params, moves the wording into one catalog, and makes `scripts/check.ts` the only renderer.

**Done when**:

- No check function composes a sentence; it names a code and passes params.
- `Finding` carries `code`, `level`, and `params`; the catalog validates at import: unique codes, known levels, every template formats with dummy params.
- Every code has a fixture, and the coverage assertion `set(CATALOG) - seen == empty` passes.
- `bun run gate` is green and the test count is recorded.

**Evidence**: `scripts/findings.ts` holds the catalog; the probe runs below.

- Call sites that build a sentence: 71 before, 0 after (`fail(` and `warn(` no longer exist in `doc-checks.ts` or `package-checks.ts`).
- 67 codes across `docs.*` (15), `budget.*` (3), `table.*` (3), `backlog.status` (1), `prose.*` (5), `package.*` (9), `board.*` (31). One `warn`: `budget.volume_soft`.
- `Finding` is `{ level, code, params, message }`; `finding()` is the only constructor and `format()` the only formatter; `scripts/check.ts` prints `finding.message` and stays the only printer.
- Import-time validation runs `problems(SPECS)` and throws: a code without a domain, a level outside the two, a template that cannot format, a template whose placeholder is left unrendered. `findings.test.ts` feeds four broken catalogs and asserts each clause fires, plus `placeholders()` on attribute, index, and format-spec forms.
- Wording moved to one shape: `location: problem`, and `path:line: problem` where a line exists. The probe prints `docs/norm/flow.md: volume 11446 exceeds 10000 (soft)`; the table stage keeps `docs/a.md:2: 1 cells, header has 2; escape a literal pipe as \|`.
- Tests: 90 before, 108 after. Assertions name codes, not sentences, so a wording change no longer touches a test. `zz-coverage.test.ts` asserts `CODES - seenCodes() == []`.
- `bun run gate`: PASS, 178 markdown files, 108 tests, 0 fail, two soft volume warnings.
