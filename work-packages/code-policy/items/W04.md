# W04 — Express the pattern in both overlays and gate it

**Depends on**: W03

C6 in each overlay README names the language expression of the message record: Python a `NamedTuple` spec, a dict catalog keyed by code, one facade that formats from params, and import-time validation; TypeScript an `as const` catalog, `Record<Code, Spec>`, and a record with a discriminant instead of a free string. Each overlay ships a stage that fails two things — a duplicate code in the merged catalog, and a digit inside a template string — wired into the gate the same way `tools/check_tables.py` is.

**Done when**:

- Both overlay READMEs state the expression under C6 and name the stage and its command.
- Each stage fails a fixture with a duplicate code and one with a digit in a template, and passes the clean fixture.
- `bun run gate` is green.

**Evidence**: both stages ship and report the same codes on the same fixture.

- `template/overlays/python/tools/check_messages.py` and `template/overlays/typescript/tools/check-messages.ts` fail `messages.unnamespaced`, `messages.template`, `messages.shape`, `messages.duplicate`, `messages.digit`, `messages.collision`, `messages.catalog`, and `messages.unloadable`.
- Wired where the table stage is: `tools/gate.py` calls the Python stage after `check_tables.py`; `package.json` adds a `messages` script that the `gate` chain calls last.
- Six fixture runs, each with both stages, identical output and exit codes: clean catalog, 2 codes, 0 findings, exit 0; four defects (unnamespaced code, positional placeholder, placeholder/param mismatch, shared wording), 5 findings, exit 1; a merge collision plus `30` typed into a template, 2 findings, exit 1; the same two codes with `exempt` naming one, 0 findings, exit 0; a catalog that raises on import, 1 finding, exit 1; no `[tool.messages]`, `no catalog declared`, exit 0.
- `ruff format --check` and `ruff check --select E,F,I,UP,B,SIM,RUF` on the Python stage: already formatted, all checks passed.
- Both READMEs carry four C6 bullets, one C7 trap, a Files row, and the stage in the C1 list; `docs/norm/overlays.md` carries the updated C1 and C6 rows; `docs/norm/code/messages.md` measures 8,874 non-whitespace characters and names the stage.
- `bun run gate`: PASS, 178 markdown files, 90 tests, 0 fail.
