# W04 — Express the pattern in both overlays and gate it

**Depends on**: W03

C6 in each overlay README names the language expression of the message record: Python a `NamedTuple` spec, a dict catalog keyed by code, one facade that formats from params, and import-time validation; TypeScript an `as const` catalog, `Record<Code, Spec>`, and a record with a discriminant instead of a free string. Each overlay ships a stage that fails two things — a duplicate code in the merged catalog, and a digit inside a template string — wired into the gate the same way `tools/check_tables.py` is.

**Done when**:

- Both overlay READMEs state the expression under C6 and name the stage and its command.
- Each stage fails a fixture with a duplicate code and one with a digit in a template, and passes the clean fixture.
- `bun run gate` is green.
